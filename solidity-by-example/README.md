# Solidity by Example 中文站

静态页面，风格对齐 [solidity-by-example.org](https://solidity-by-example.org/)，内容来自 [Solidity-by-example_Chinese](https://github.com/Web3-Club/Solidity-by-example_Chinese)。

本地预览（在仓库根目录）：

```
python3 -m http.server 8765
```

打开 http://127.0.0.1:8765/solidity-by-example/

重新生成页面：

```
python3 solidity-by-example/build.py
```

`build.py` 默认读取本机 `WritersideProjects/solidity-by-example_Chinese`。
